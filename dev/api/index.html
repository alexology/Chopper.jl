API

Chopper.Chopper — Module
Chopper

Filtering and trimming of long-read FASTQ files (Oxford Nanopore, PacBio): a native Julia port of the Rust tool chopper 0.14.1 by Wouter De Coster.

Reads are filtered on mean quality, length, GC content and similarity to contaminant sequences, then optionally trimmed with one of four strategies (FixedCrop, TrimByQuality, BestReadSegment, SplitByLowQuality). The main entry point is chopper; the same filters are available per read through read_segments.

Filtering files

Chopper.ChopperStats — Type
ChopperStats

Counts returned by chopper:

  • reads, bases: reads and bases read;
  • segments, kept_bases: records and bases written; segments is the number that chopper reports as "Kept N reads";
  • kept_reads: reads with at least one written record;
  • passed: reads that passed all filters (with inverse, these are the discarded ones);
  • failed_length, failed_quality, failed_gc, contaminants: reads by the first filter they failed;
  • trimmed_away: reads selected by the filters but with no segment left after trimming (or none long enough);
  • reads_with_mods: reads that carried an MM tag (only counted with update_mods).

Chopper.chopper — Function
chopper(input, output = stdout; kwargs...) -> ChopperStats

Filter and trim the reads of the FASTQ input and write the selected reads to output, as the command-line tool chopper does. input is a path or an IO (compressed input is recognised automatically, see open_fastq); output is a path (gzip-compressed if it ends in .gz) or an IO (not closed). Returns the counts as a ChopperStats.

A path output is written to a temporary file in the same directory and renamed over output only when the run succeeds: after an error the file is missing or unchanged, never partial, also when the rename itself fails (for example on a file locked by another program). A replaced file keeps its permissions. Bytes already written to an IO (such as stdout) cannot be taken back: after an error that output is incomplete.

An input stream is not closed. Compressed input may be read ahead by a separate task: after an error chopper returns without waiting for a read of that stream still in progress (which could wait for data forever, as on a pipe); the task stops when the read returns or the stream is closed.

Keywords:

  • the filters of ReadFilter: min_quality, max_quality, min_length, max_length, min_gc, max_gc, contaminants, contaminant_fraction; or filter, a ReadFilter, instead of them;
  • trim = NoTrim(): the trimming strategy, FixedCrop, TrimByQuality, BestReadSegment or SplitByLowQuality;
  • inverse = false: write the reads that fail the filters instead;
  • update_mods = false: rewrite the base modification tags MM, ML and MN for the trimmed reads (see rewrite_mod_tags); a read whose tags cannot be rewritten raises a ModTagError;
  • threads = Threads.nthreads(): tasks processing batches in parallel. The output is identical for any number of threads;
  • batch_bases = 4_000_000, batch_reads = 10_000: size of a batch.

Filters judge the whole read; trimming is applied afterwards to the reads they select, and only the minimum length is checked again on each segment. In particular the mean quality is not recomputed for trimmed segments.

Filters and single reads

Chopper.ReadFilter — Type
ReadFilter(; min_quality = 0, max_quality = 1000, min_length = 1,
           max_length = typemax(Int), min_gc = nothing, max_gc = nothing,
           contaminants = nothing, contaminant_fraction = 0.9)

Filters applied to whole, untrimmed reads, as chopper's filtering options:

keywordchopper
min_quality, max_quality-q, --maxqualmean quality (mean_quality)
min_length, max_length-l, --maxlengthread length; min_length is checked again on trimmed segments
min_gc, max_gc--mingc, --maxgcGC fraction, 0–1 (gc_content)
contaminants-ca ContaminantIndex or the path of a FASTA file
contaminant_fraction(fixed 0.9)see is_contaminant

As in chopper, the quality filter is evaluated only if min_quality > 0 or max_quality < 1000, and the GC filter only if min_gc or max_gc is set: with the defaults, reads of any quality (or GC content) pass.

Chopper.read_segments — Function
read_segments(seq, qual; filter = ReadFilter(), trim = NoTrim(), inverse = false)
    -> Vector{UnitRange{Int}}

Ranges of the read that chopper would write: empty if the read is discarded, one range per written record otherwise (several when trim splits it).

The filters judge the whole read; then the trimming strategy is applied and each trimmed segment shorter than filter.min_length is dropped (not with NoTrim). With inverse = true the reads that fail a filter are kept and trimmed instead, as chopper's --inverse.

Trimming strategies

Chopper.BestReadSegment — Type
BestReadSegment(cutoff)

Keep the single segment of the read with the highest score, where every base scores p(cutoff) - p(q) and p is the error probability of a Phred score (--trim-approach best-read-segment --cutoff cutoff). This is the modified Mott algorithm of Phred quality trimming: bases better than cutoff contribute positively, worse bases negatively. Among segments with the same score the longest (then the first) is kept. A read whose bases are all worse than cutoff is discarded.

source
Chopper.FixedCrop — Type
FixedCrop(head, tail)

Remove head bases from the start and tail bases from the end of every read (--trim-approach fixed-crop --headcrop head --tailcrop tail). Reads not longer than head + tail are discarded. At least one of the two must be positive.

source
Chopper.NoTrim — Type
NoTrim()

Keep the whole read. With this strategy (the default) the minimum length is not checked a second time after trimming, as in chopper without --trim-approach.

source
Chopper.SplitByLowQuality — Type
SplitByLowQuality(cutoff; window = 1)

Split reads at runs of at least window consecutive bases with a Phred score below cutoff, and keep the high-quality parts between them (--trim-approach split-by-low-quality --cutoff cutoff --split-window window). Shorter low-quality runs stay inside their segment; low-quality bases at the ends of a segment are removed. Each part must still reach the minimum read length to be written; parts are named <read>_segment_<n>. A window of 0 is treated as 1.

source
Chopper.TrimByQuality — Type
TrimByQuality(cutoff)

Trim bases with a Phred score below cutoff from both ends of the read, stopping at the first base with score >= cutoff on each side (--trim-approach trim-by-quality --cutoff cutoff). Low-quality bases inside the read are kept. A read without any base >= cutoff is discarded.

source

TrimStrategy

Abstract type of the trimming strategies. A strategy s implements trim_ranges!(out, s, qual), which empties out, fills it with the ranges (UnitRange{Int}, 1-based) of the read to keep, in increasing order, and returns it. qual holds the raw Phred+33 bytes of the quality line.

Quality and GC content

Chopper.gc_content — Function
gc_content(seq::AbstractVector{UInt8}) -> Float64

Fraction of G/C bases (either case) among all bases of seq, including N and other symbols in the denominator, as in chopper. An empty sequence gives NaN.

source
Chopper.mean_quality — Function
mean_quality(qual::AbstractVector{UInt8}) -> Float64

Mean quality of a read, from the raw Phred+33 bytes of its quality line, computed as chopper (and NanoFilt) do: the Phred scores are converted to error probabilities, averaged, and the mean probability is converted back to a Phred score, -10 log10(mean(p)). This is lower than the arithmetic mean of the scores whenever the scores vary.

The sum runs left to right, as in chopper. The result can differ from chopper's in the last bit (Julia's exp10 and log10 against the C library's), which matters only for a read whose mean quality lies exactly on a threshold. An empty read gives NaN.

Contaminant screen

Chopper.ContaminantIndex — Type
ContaminantIndex(fasta; k = 19, w = 19)
ContaminantIndex(names, sequences; k = 19, w = 19)

Minimap2 index of contaminant sequences (e.g. the lambda phage control DNA of ONT kits, or a host genome) for is_contaminant and the contaminants option of chopper and ReadFilter. Reads are mapped with the minimap2 preset lr:hq and base-level alignment, as chopper does; k and w override the preset's minimizer length and window.

The index is only read while mapping and can be shared by any number of tasks.

Modification tags

Chopper.ModTagError — Type
ModTagError

Base modification tags of a read that cannot be rewritten: malformed MM, ML or MN tags, MM and ML with different numbers of calls, an MM tag that refers to more bases than the read has, an MN tag with a different read length, or ML without MM. Fields: kind, one of :malformed_mm, :malformed_ml, :malformed_mn, :count_mismatch, :beyond_sequence, :stale_mn, :ml_without_mm; msg; read, the read name (empty if not known).

source
Chopper.rewrite_mod_tags — Function
rewrite_mod_tags(fields, seq, range) -> Vector{String}

Rewrite the base modification tags among the tab-separated SAM tag fields of a read with sequence seq (bytes or string) so that they describe the subsequence seq[range]:

  • MM:Z: keeps only the calls inside range, with recomputed skip counts;
  • ML:B:C keeps the probabilities of those calls;
  • MN:i: becomes length(range); it must equal the length of seq.

Other fields are returned unchanged, including tags that trimming also invalidates (qs, ns, ts, du, ...). Tag names are matched without regard to case (Mm/Ml of older basecallers). Throws ModTagError if the tags are malformed or do not describe seq.

Input

Chopper.open_fastq — Function
open_fastq(path::AbstractString) -> TranscodingStream
open_fastq(io::IO) -> TranscodingStream

Open a FASTQ file or stream for reading, decompressing it if needed. The format is recognised from the first bytes, not from the file name: gzip (always available, also multi-member files such as those of pigz or bgzip), bzip2, xz and zstd (with the packages CodecBzip2, CodecXz and CodecZstd installed). Closing the returned stream closes path's file, or io.
